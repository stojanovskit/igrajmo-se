# Играјмо.се — македонски друштвени игри

Бесплатна, account-free колекција на десет игри за двајца, инспирирана од старата заедница на `igrajmo.se`. Посетителот внесува само прекар, добива код на соба и може веднаш да игра со пријател или со првиот слободен противник.

## Игри

- Не лути се човече
- Меморија
- Шах
- Домино
- Скицирка
- Тарок
- Потопување бродови
- Јамб
- Жандар
- Кугликс

Секоја игра има жива соба за двајца. Скриените карти, зборови и бродови се филтрираат на серверот и не му се испраќаат на противникот.

## Локално стартување

Потребни се Node.js 22.13 или понова верзија и Cloudflare Wrangler.

```bash
npm install
npm run dev
```

Локалната D1 база се создава автоматски од апликацијата. За проверка:

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Објавување

Проектот е подготвен за Cloudflare Workers + D1:

```bash
npm run deploy
```

За автоматско објавување преку GitHub Actions, во repository secrets додади `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`. Токенот треба да има Workers Scripts и D1 write дозволи.

Live: [igrajmo-se.stojanovskit2022.workers.dev](https://igrajmo-se.stojanovskit2022.workers.dev)

## Приватност

Нема регистрации, лозинки, е-пошта, профили или реклами. Прекарот и случајниот идентификатор остануваат во browser storage; во базата се чува само состојбата на партиите.

Ова е независна community recreation и не тврди сопственост врз оригиналниот бренд или код на поранешната страница.
